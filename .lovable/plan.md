# Flip Fade Headline Animation

## Goal
Apply the existing VengeanceUI Flip Fade animation to both highlighted headings shown in the references:
- “Discover the Hidden Beauty of Bentota”
- “An intimate escape into the untamed beauty of the river.”

## Implementation
- Reuse the already-installed `FlipFadeText` component; do not reinstall or duplicate it.
- Extend it with a single-text mode so each full headline animates into view without rotating through unrelated words.
- Preserve the current wording, serif/italic styling, alignment, spacing, and surrounding layout.
- Keep animation restrained and compatible with reduced-motion preferences.
- Verify desktop and narrow mobile presentation, navigation, and runtime health.

## Scope
No images, sections, content, routes, or other animations will be changed.
